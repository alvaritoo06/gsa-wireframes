# GSA · Gestión de solicitudes de arbitraje — Wireframes

Prototipo navegable de baja fidelidad del Laboratorio 03 de Fundamentos de Sistemas de Información (PUCP, 2026-2), Grupo 28.

- **36 wireframes** enlazados entre sí, diseñados en draw.io.
- Cubren los **95 DFD** fragmentados del proceso: 84 procesos con pantalla y 11 automáticos.
- Cada pantalla indica los requerimientos (RF-GSA) y los procesos del DFD que implementa.

## Ver la página

Abre `index.html` en el navegador o publícala con GitHub Pages:
**Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`**.

## Estructura

```
index.html                              página única (HTML + CSS + JS, sin dependencias)
assets/wireframes/*.svg                 una imagen por pantalla
assets/Wireframes_GSA_Grupo28.drawio    archivo fuente editable
```

Se puede enlazar directo a una pantalla con `#w-<id>`, por ejemplo `index.html#w-c_rev`.
